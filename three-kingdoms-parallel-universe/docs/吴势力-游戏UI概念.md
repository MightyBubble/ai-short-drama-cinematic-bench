# 三国：平行宇宙 — 吴势力 · 游戏内界面概念

## 1. 概述

吴线 UI = **夜港控制室**：青蓝雾底、冷 CRT、蓝声呐环、橘指针。  
风格锚点：Spider-Verse 印刷感 + Expedition 33 / Persona 4 Reload。  
配色 **7:2:1**：青蓝(~70%) / 蓝(~20%) / 橘(~10%，仅指针与锁定)。

## 2. 结构

| 界面 | Mood | 成品图 |
|------|------|--------|
| 战斗 HUD | 贴窗疾驶的声呐电台 | `ui/ui-wu-battle.png` |
| 养成/构筑 | 港务调度台频率校准 | `ui/ui-wu-build.png` |
| 主菜单 | 雨巷尽头通联站 | `ui/ui-wu-menu.png` |
| 城市冒险 | 雨巷抄近路听声辨位 | `ui/ui-wu-city.png` |

## 3. 详情

- **材质：** CRT 磷光玻璃、湿金属、半调雾、哑光橘漆指针  
- **动效：** 声呐脉冲、指针甩入、扫描线烧录、换台色阶错位  
- **生图禁入：** 三国人名、古装史诗、水墨书法  

## 4. 场景

主菜单起调电台 → 城市港区 → 战斗同一仪表语言 → 战后频率碎片进构筑。

## 5. 边界

橘不铺底；不做古装水师、龙纹庙堂、贴纸徽章压主视觉。
