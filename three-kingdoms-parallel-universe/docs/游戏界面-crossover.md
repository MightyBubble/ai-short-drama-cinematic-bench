# 游戏界面 — crossover 渲染（战斗 / 主菜单 / 城市）

> 完整英文 prompt 见 `../IP设计.md` §3.D。  
> 魏 / 蜀 / 吴不再各做一套网点皮肤；三张界面本身就是多管线撞车。

## 1. 概述

UI 的**信息层级**学 Expedition 33（字入画）与 Persona 4 Reload（大字、疏菜单、一屏一焦点）。  
UI 的**物质**来自作者管线：Nihei 排线、Yagi/90s 赛璐珞色块、Sidonia 几何、Gauna 膜、Ogura 水粉。  
控件压到世界或角色上必须发生接触带感染。禁止网点贴纸层、禁止玻璃拟态 HUD。

## 2. 结构

| 界面 | 世界管线撞车 | UI 物质如何分配 |
|------|--------------|-----------------|
| 战斗 HUD | Claymore 赛璐珞骑士 × BLAME! 巨构敌 | 血条=排线密度计；技能=赛璐珞色块；锁定=Sidonia 几何环 |
| 主菜单 | 左魏巨构 / 中蜀斗篷 / 右吴膜雨 | 标题字三分介质；P4R 疏列命令 |
| 城市冒险 | Ogura 街 + 长出的巨构 + Gauna 运河 | 目标条=水粉纸；小地图=几何碎片；互动字写在真实墙上并随墙感染 |

## 3. 详情

势力色仍是 7:2:1，但跟**控件所属管线**走，不是给整屏套队服。

- 魏控件：黑金红，排线、结构光、杀伤狭缝。
- 蜀控件：红白蓝，赛璐珞 2-3 阶、youki 只做选中。
- 吴控件：青蓝橘，几何环与膜，橘只做刻度。

Prompt 正文：`IP设计.md` D1–D3。

## 4. 场景

开战读连招与弱点（E33 入画字 + P4R 大技能名）→ 回标题看到三宇宙建筑撞车 → 进城时 UI 写在路上的物质里。

## 5. 边界

**做：** 作者材质控件 + 接触带感染 + 疏层级。  
**不做：** 全屏半调贴纸、偶像海报封面菜单、密图标玻璃 HUD、古装军令状、水墨招牌。

## 6. UAT

```gherkin
Scenario: 三张 UI 不是贴纸层
  Given 打开战斗、主菜单、城市概念
  When 检查控件与世界的重叠边
  Then 重叠处应改写彼此的介质
  And 信息应可在 2 秒内读到焦点
  And 不应看到统一网点装饰贴在通用 HUD 上
```
