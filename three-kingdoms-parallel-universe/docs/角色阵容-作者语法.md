# 角色阵容 — 作者语法（取代上一版娱乐业转译）

> 完整 prompt 与管线定义见 `../IP设计.md` §3.C。  
> 本页只保留九人索引，避免再把职能写成舞台身份。

## 1. 概述

角色是**渲染管线里的操作体**：Claymore 银眼骑士、Nihei 巨构里的尘埃驾驶员、Sidonia 种子船与 Gauna 膜上的掠行体。  
禁止把当代理解成娱乐业。Hydro Skater 的 Skater = 几何水翼掠膜，不是滑板。

## 2. 结构

| 势力管线 | 代号 | 作者语法 |
|----------|------|----------|
| 蜀 · Yagi + 90s 赛璐珞 / Ogura | Scarlet Oathblade, White Lance Ace, Oracle Architect | 银眼、巨兵器、斗篷剪影、youki；2-3 阶赛璐珞 |
| 魏 · Nihei BLAME! + Sidonia 几何 | Siege Hammer, Night Raid Fox, Iron Bastion | 排线体积、人像尘埃、切面机体、金结构光 |
| 吴 · Sidonia Gauna + Patlabor 2 / Ogura | Tide Captain, Hydro Skater, Mist Tactician | 种子船束具、水翼掠膜、膜雾、橘警告 |

配色 7:2:1：蜀红白蓝 / 魏黑金红 / 吴青蓝橘。

全身英文 prompt 见 `IP设计.md` C1–C9。

## 4. 场景

图鉴全身用 C；与另一管线同框时改走 B 的 CONTACT BELT，不要给角色另做一套「时装皮肤」。

## 5. 边界

**合格：** 去掉特效后仍能指认 Yagi / Nihei / Sidonia / Ogura。  
**重做：** 去掉特效后像舞台人、耳麦、滑板、时尚编辑照。  
禁止古人名、古装、水墨、书法。
