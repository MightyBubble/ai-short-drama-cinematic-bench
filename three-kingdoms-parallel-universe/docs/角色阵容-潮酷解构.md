# 三国：平行宇宙 — 角色阵容潮酷解构

## 1. 概述

把五虎将 / 五谋士 / 五子良将拆成**职能席位**，再按 Persona 逻辑转译：  
传统符号 → 现代职业/街头身份 → 夸张时尚剪影 → 可折叠现代道具。  
分析层可对应历史职能；**生图层只用英文代号**，禁止古人名与古装盔甲。

## 4. 场景

- 战斗立绘：猛将 / 精锐 / 机动手  
- 养成界面：智囊 / 后勤 / 战术导演  
- 城市镜头：外交、港湾、夜巷潜入  

## 5. 边界

**合格：** 去掉特效后仍像能走在潮店的人。  
**重做：** 去掉特效后仍像影视城古装龙套。

## 6. UAT

Scenario: 立绘一眼潮酷

  And 武器呈现可折叠现代物隐喻
  And 不出现中国古人名与古装盔甲观感
