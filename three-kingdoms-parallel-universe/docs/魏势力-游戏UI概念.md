# 三国：平行宇宙 — 魏势力 · 游戏内界面概念

## 1. 概述

魏线 UI = **精英执法机器**：黑底压迫场、金色律法刻度、红色告警脉冲。  
风格锚点：Spider-Verse 印刷感 + Expedition 33 / Persona 4 Reload 游戏内 UI。  
配色 **7:2:1**：黑(~70%) / 金(~20%) / 红(~10%，仅告警与拒斥)。

## 2. 结构

| 界面 | Mood | 成品图 |
|------|------|--------|
| 战斗 HUD | 防暴指挥台压进视野边缘 | `ui/ui-wei-battle.png` |
| 养成/构筑 | 精英实验室冷规则拼装 | `ui/ui-wei-build.png` |
| 主菜单 | 律法大厦开机仪式 | `ui/ui-wei-menu.png` |
| 城市冒险 | 宵禁街区战术漫游 | `ui/ui-wei-city.png` |

## 3. 详情

- **材质：** 哑光装甲黑、烫金刻度、半调网点、CMYK 错版、防弹视窗感  
- **动效：** 错版闪、网点扩散、分格裁切、金色路径生长、红拒斥震颤  
- **生图禁入：** 三国人名、古装史诗、水墨书法  

## 4. 场景

玩家第一眼应感到「权限与刻度」：黑是空气，金是许可，红是例外。

## 5. 边界

红从不装饰；不做紫炫光、奶油纸、神殿感、古装甲胄。

## 6. UAT

```gherkin
Scenario: 魏战斗 HUD 配色合规
  Given 玩家进入魏线战斗
  When HUD 可见且无超载告警
  Then 界面约 70% 黑、20% 金
  And 红仅出现在威胁/警告且约 10%
```
