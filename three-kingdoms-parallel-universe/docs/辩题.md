# 辩题：三国本来就是平行宇宙

## 1. 概述

上一题辩成了「给暗黑科幻截图贴中文界面」。  
玩家既认不出三国，也感受不到平行宇宙——只觉得像在看别人的科幻同人。

**新辩题：**  
民间早就把同一批人画成无数种版本。这款游戏把每个版本做成一种**印刷术**，打在同一帧里。

你走进去的不是古装片，也不是潮牌街拍，而是：  
**小人书的街，被港漫的墨撕开；墙上的年画走下来，变成能操作的角色。**

这才是 Spider-Verse 的方法：不是全员套一张网点，而是**两种印刷术在接触带互相感染**。  
这才是三国：不是点名武将，而是你一眼能感到「这类人在中国民间被印过无数次」。

## 2. 结构（三种印刷宇宙 = 三势力）

| 势力 | 印刷术（点名流派） | 色 7:2:1 | 玩家怎么认 |
|------|-------------------|----------|------------|
| 魏 | 70s 北派丝网宣传画 + 硬边工业刻板 | 黑 / 金 / 红 | 秩序、许可、警告条，人被版画压扁 |
| 蜀 | 贺友直式连环画人情 + 马荣成港漫刀墨 | 红 / 白 / 蓝 | 红披风是年画油墨，刃是港漫速线 |
| 吴 | 杜可风 90s 港片夜雨 + 南方港口连环画 | 青蓝 / 蓝 / 橘 | 钠灯、湿街、警告灯，像旧录像带 |

共享底片：90s 赛璐珞 2–3 阶阴影、胶片颗粒。  
碰撞法：Spider-Verse 的接触带感染——小人书排线爬上港漫披风，丝网金边把赛璐珞咬成刻板。

## 3. 详情：题为什么总辩输

| 旧辩法 | 模型听成什么 | 玩家看到什么 |
|--------|--------------|--------------|
| 三国人名 / 古装 | 影视城盔甲 | 历史剧海报 |
| 「潮酷」 | 耳麦、卫衣、夜店 | 农村非主流 |
| 只写 Spider-Verse | 全员半调贴纸 | 滤镜，不是宇宙 |
| BLAME + 大剑硬套 | 日本暗黑科幻 | 丢了三国，也丢了好玩 |
| 中文 HUD 贴上去 | 概念图 + 翻译界面 | 不像在玩 |

**Persona 式解构要辩的是民间符号，不是职业装。**  
关公职能 = 年画门神的红与刀，印在一个能走路的人身上。  
不要写成「偶像主唱」，也不要写成「银发欧洲剑士」。

## 4. 场景（玩家第一眼必须成立）

1. **开场街**：你走在贺友直式小人书小镇，招牌是木刻字，人是平涂。  
2. **开战**：页被撕开，马荣成港漫的墨与速线砸进来——这就是进入异世界。  
3. **魏境**：整条街变成丝网刻板，金是许可，红是禁区。  
4. **吴境**：杜可风的雨和青蓝橘，港口从小人书里洇成录像带。  
5. **人物检视**：脸上是东亚骨相、黑发；身上能指出「哪一块是年画油墨，哪一块是港漫线」。

## 5. 边界

**做：** 连环画、港漫、丝网、90s 港片摄影、东亚面孔、中文界面、接触带感染。  
**不做：** 古装史诗、水墨书法、潮牌耳麦、纯 BLAME 无中国印刷、全员同一滤镜。

## 6. UAT

```gherkin
Scenario: 新玩家三秒能说出这是什么游戏
  Given 打开一张开场街或开战截图

  And 不应感到「日本暗黑科幻」或「古装历史剧」或「潮牌广告」
```
