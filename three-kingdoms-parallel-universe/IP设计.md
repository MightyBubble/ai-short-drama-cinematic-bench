# 三国：平行宇宙 — IP / 游戏视觉概念设计

## 1. 概述

《三国：平行宇宙》是一套以「乱世三国」为母题、以平行宇宙碰撞为玩法入口的原创 IP 视觉概念。  
视觉语法向《蜘蛛侠：平行宇宙》三部曲学习：**印刷感优先、一宇宙一材质、情绪驱动色板**；内容主体仍是三国人物、城阙、水寨与战火，不搬运任何版权角色或标志。

一句话卖点：  
**每个三国世界一种画法；你穿越过去，盔甲也会被那个世界的笔触改写。**

## 2. 结构

| 层 | 内容 | 玩家感知 |
|---|---|---|
| IP 品牌层 | 主标题「三国：平行宇宙」、朱砂印章、竖排匾额字 | 一眼认出这是三国，不是西式超级英雄 |
| 主宇宙锚点 | 网点 + 墨线 + 朱青撞色 | 「我的世界」长什么样 |
| 分宇宙系统 | 魏 / 蜀 / 吴 / 黄巾 / 裂隙各一套材质 | 「换世界 = 换画风」 |
| 角色剪影层 | 武将近景、军师情绪宇宙 | 靠轮廓认人，不靠写实脸 |
| 冲突表现层 | 跨宇宙对决、分格战场、冲击帧 | 动作像翻漫画，不像镜头糊掉 |
| BOSS / 终局层 | 「未完成之帝」负空间裂隙 | 天命崩坏的抽象压迫感 |

本合集共 8 张概念图，覆盖上述六层。

## 3. 详情

### 3.1 从三部曲借来的语法（可执行）

- **Into**：半色调网点、排线阴影、套印错位、粗轮廓、不用镜头模糊  
- **Across**：一宇宙一介质（马克笔 / 水彩 / 网点 / 油印拼贴）  
- **Beyond**：近景墨线毛边、竖构图细节密度、更抽象的裂隙负空间  

### 3.2 分宇宙材质 SSOT

| 宇宙 | 材质标签 | 色板 | 代表画面 |
|---|---|---|---|
| 魏 · 秩序城 | 冷马克笔叠透 | 青灰、冷金 | `02` 左幅 |
| 蜀 · 人情山城 | 水彩洇染 + 情绪变色 | 暖茶、竹青、琥珀 | `02` 中幅、`07` |
| 吴 · 潮汐水寨 | 网点印刷 + 图形浪纹 | 青绿、墨、朱红点缀 | `02` 右幅 |
| 黄巾 · 地下油印 | Xerox 拼贴、胶带、错印 | 芥黄、烟灰、朱砂 | `06` |
| 裂隙 · 天命崩坏 | 未完成线稿 + 泼墨负空间 | 纸白、蓝铅笔、墨黑 | `05` |

### 3.3 角色与冲突规则

- 阴影用网点/排线，不用柔光渐变。  
- 动作用残影、速度线、分格冲击帧，不用默认运动模糊。  
- 跨界时发生「材质感染」：水墨将军进马克笔魏都，盔甲也会渗墨。  
- 拟声用汉字（锵、轰），不用英文 POW/BAM。

## 4. 场景

| 玩家会看到 | 对应图 | 要传达的感觉 |
|---|---|---|
| 打开游戏 / 宣传片第一帧 | 01 主视觉 | 三国乱世被撕开，多重世界撞在一起 |

| 角色图鉴 · 武将 | 03 竖幅近景 | 「这把刀、这张脸，我记住了」 |
| 跨界决斗预告 | 04 对决 | 红与青两种画法正面相撞 |

| 叛军支线入口 | 06 黄巾 | 粗糙、愤怒、像街头油印传单 |

## 5. 边界

**做：**

- 三国建筑语法（城阙、水寨、旌旗、甲胄）  
- 印刷语言（网点、排线、套印错位、可见笔触）  
- 原创角色造型与原创 BOSS 概念  

**不做：**

- 蜘蛛标志、蛛网符号、任何版权超级英雄造型  
- 把布鲁克林/曼哈顿当主视觉  
- 满屏英文拟声  
- 紫粉霓虹默认「AI 科幻风」  
- 写实 PBR 皮肤/金属盖过插画感  
- 用杂色噪点冒充半色调网点  

## 6. UAT（Cucumber BDD · 玩家视角）

```gherkin
Feature: 三国平行宇宙概念图合集能让新玩家一眼看懂世界观
  作为一名第一次接触这个 IP 的玩家
  我希望只看图就能明白「三国 + 多世界 + 不同画风」
  以便决定要不要继续了解玩法

  Scenario: 主视觉建立品牌与冲突
    Given 我打开概念图合集首页
    When 我看到第一张主视觉
    Then 我应先看到标题「三国：平行宇宙」而不是一堆杂乱信息
    And 我应看到至少两个被撕裂的世界同框
    And 画面应有印刷网点或墨线感，而不是写实照片感

  Scenario: 三联宇宙让我分清魏蜀吴
    Given 我在浏览世界设计
    When 我查看魏蜀吴三联图
    Then 三幅画应明显属于三种不同画法
    And 我应能凭颜色与场景猜出水军、山城、秩序大城的差异
    And 我不需要读长文说明也能感觉到「换世界会换风格」

  Scenario: 武将近景让我认人
    Given 我在看角色概念
    When 我打开竖幅武将近景
    Then 角色剪影与兵器应在一秒内可辨认
    And 甲胄与刀锋上应有清晰的网点或墨线细节
    And 背景应提示平行宇宙，而不是普通历史剧照

  Scenario: 对决图讲清「材质对撞」
    Given 我已经看过不同宇宙的画风
    When 我查看跨宇宙对决图
    Then 交战双方应呈现两种不同材质/色温
    And 碰撞中心应有冲击感（残影、速度线或分格能量）
    And 我不觉得这是普通的历史武将对砍海报

  Scenario: BOSS 图传达终局威胁
    Given 我滑到裂隙 BOSS 概念
    When 我盯着「未完成之帝」
    Then 我应感到角色像「没画完却已能吞掉世界」
    And 画面应出现负空间、线稿或泼墨裂隙
    And 我不应认出任何现成超级英雄反派造型

  Scenario: 分格战场让我理解动画气质
    Given 我想知道战斗过场长什么样
    When 我查看分格战场概念
    Then 我应看到多格叙事，而不是单张写实剧照
    And 拟声若出现，应是汉字而不是英文漫画拟声
    And 我能想象自己在玩一款「会动的连环画三国」
```
